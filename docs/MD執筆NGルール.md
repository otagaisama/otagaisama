# MD執筆NGルール（docs/・HANDOFF.md 共通）
> 前提：リポジトリはpublic。書いた瞬間、世界公開。

## 🔴 絶対NG（1文字も書かない）
1. **鍵・認証情報すべて**
   - Supabase secret / service_role キー
   - Web3Forms等の外部サービスキー
   - パスワード・アクセストークン・PIN
   - DB接続文字列（Session poolerのパスワード入りURI）
2. **parent_token（親QRトークン）**
   - bearer＝書いた瞬間に誰でもclaim可能になる。メール送付のみの原則どおり
3. **未修正の脆弱性の詳細**
   - 例：profiles権限問題は「修正SQL実行完了」までdocs/に書かない
   - 攻撃手順つきで公開するのと同じことになる
4. **個人情報**
   - 実在人物の本名・メール・住所・電話
   - short_id/global_noと実在人物の対応（例：dby5db=◯◯さん）
   - カード当事者のメッセージ本文（当事者のみ原則と整合）

## 🟡 書かない方針（危険ではないが表に出さない）
- 最深部の動機の話（看板に出さない方針どおり）
- 取引先との未公開の交渉内容・見積もり
- anon key（公開前提の鍵やが、MDにわざわざ転記しない）

## 🟢 書いてOK
- 設計思想・決定事項・状態遷移
- テーブル名・カラム名・ファイル名・RPC名
- 修正済みの不具合の経緯（原因と対処）

## 運用
- Claudeは今後MD出力時、このルールで自主検閲してから出す
- TAKAがdocs/にアップ後、raw URL群をClaudeに渡す → NGパターン一括スキャン
