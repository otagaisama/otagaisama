# 電気通信事業法・判断地図
出所: Claude（Fable）調査×TAKA ／ 初版: 2026-07-19 ／ 最終更新: 2026-07-24
※法的助言ではない。最終確認は管轄の総合通信局へ（電話・無料）

## 該当性と要否
- こころづての1対1メッセージ交換は「他人の通信の媒介」に構造上該当
- ただし届出要否は「営む」＝営利性で決まる。名目無料でも協賛・広告収入があれば実質営利
- 現状（収益ゼロ）: 届出不要の公算
- スポンサー収益開始 → 届出要の公算大。区分は「届出を要する電気通信事業」（登録は不要・
  書類提出のみ・個人可・管轄は総合通信局）
- 届出タイミング: スポンサー営業開始の直前

## 届出後に発生する義務
- 届出後は「通信の秘密」が正面適用 → 運営者がメッセージを閲覧しうる設計は
  利用規約での明示同意が必須。評価に用いない旨も併記
- 併せて対応: 外部送信規律（Cookie規制）・電気通信分野の個人情報ガイドライン

## 届出の実務（2026-07-24追記）
- 届け出る内容に「氏名または会社名・住所」が含まれる（法人はさらに代表者氏名）
- 添付書類: 個人は住民票の写し（原本・コピー不可）／法人は登記事項証明書
  → **個人名義の届出はバーチャルオフィス住所では通らない。実住所（住民票の住所）になる**
- 審査期間はないが、届出番号の発行処理に2週間程度
- 届出後、事業者名等が総務省HPの「届出電気通信事業者一覧」に公示される
  → **個人名義だと本名が国のサイトに載る可能性がある。要事前確認（公示項目の範囲）**

## 【要判断】個人のまま届出するか、法人化してからか（2026-07-24起票）
判断タイミング: スポンサー営業を始める前。ドメイン取得より後、印刷・公開の後でよい。

| | 個人のまま | 法人化してから |
|---|---|---|
| 届出の住所 | 実住所（住民票）。バーチャルオフィス不可 | 登記住所。バーチャルオフィス可 |
| 公示される名前 | 本名の可能性 | 法人名 |
| whois名義 | 個人名（代理公開で非表示） | 法人名に変更可 |
| コスト | 低 | 登記費用＋維持コスト |

- 論点: whoisで氏名・住所を隠しても、個人名義の届出で本名が公示されれば意味が薄れる
- 論点: スポンサー（神社・施設・企業）との契約書・請求書にも住所を書く場面がある。
  ここは届出とは別に、営業用の住所としてバーチャルオフィスが効く
- 現時点の傾向: 収益の見込みが立った段階で法人化 → 法人名で届出、が一番きれいに収まる。
  ただし登記費用と維持コストが発生するため前倒しはしない（エスカレーション原則）

## 隣接論点（混同しないための整理）
- **特定商取引法**: 対象は消費者への販売。本プロジェクトはユーザーに一切課金せず
  収益はスポンサーのみ＝事業者間取引のため、表記義務はかからない公算。
  法的安全三原則（カード無償・ポイント無償付与・収益はスポンサー側のみ）が効いている。
  ただしユーザー課金を一切導入しないことが前提条件
- **whois（ドメインの登記簿）**: 電気通信事業法の届出とは無関係。代理公開で氏名・住所を隠せる。
  heartcloak.com は2026-07-26取得済み・XServer Inc.名義で代理公開確定
- **運営者情報ページ**: 法的義務ではなく信頼のための任意掲示。匿名運営は「怪しい」の材料に
  なるため、whoisは隠しつつサイト上では名乗る、という分離が現実的
