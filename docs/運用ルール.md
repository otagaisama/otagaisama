# docs/運用ルール
最終更新: 2026-07-14

1. **テーマ1本＝正1枚。** 同テーマの2枚目は作らず、既存を上書き更新
2. **ファイル名に日付を入れる**（形式は自由: _2026-07-04 / _20260705 どちらも可）。矛盾時は日付の新しい方が正
3. **HANDOFF.mdは薄く保つ**（現在地と次の一手のみ）。更新はClaudeに全文出力を頼み、丸ごと差し替え
4. **HANDOFFの目次行**は「実装の土台になる正MD」だけ足す。作業用ファイルは足さない
5. **アップ後はClaudeがNGスキャン**（NGルール.md準拠）。人物とshort_idの対応は書かない
6. **作業用ファイル**（チェックリスト等）は役目を終えたら削除
7. **アップ順は前後してよい。** docs/が揃った時点でClaudeが横断で矛盾チェック
8. **DBに流したSQLはアップ不要**（原本はDBから吸い出せる）。保管したい関数だけ吸い出して置く
- ⑦補足（2026-07-29）：raw.githubusercontent.com は日本語ファイル名
  （URLエンコード）だとタイムスタンプ付きでもキャッシュが数分抜けない。
  差し替え確認は github.com/<owner>/<repo>/blob/main/... を直接見るか、
  `curl -sL "https://github.com/.../raw/main/<path>"` の別ルートも併用する。
  raw単独で「未反映」と判断しない（7/29に3回誤報）。
